# Bonebroke

A Minecraft **Fabric 1.21.1** mod. You start $2,500 in debt to a loan shark, and the Ender Dragon is your deadline. Gamble, borrow and sell your own body parts to be debt free before it dies.

**Download:** grab the files from the [latest release](https://github.com/Justinofrfr/bonebroke/releases/latest).

## Features

- **Casino (press B):** Slots, Cases, Wheel, Upgrader and Blackjack, with a bet slider. Slots are free, the rest unlock with cash.
- **Every item has a price:** hover any item to see its value and sell it in the Sell tab, or bet your inventory in the Upgrader.
- **Loan shark:** borrow when you're broke. Debt grows with interest.
- **Body shop:** sell an eye, arm, leg, kidney or your tongue. Each one has a real effect (half-black screen, can't move, can't break blocks, fewer hearts, muffled voice).
- **Random conditions every 5 minutes:** scoliosis, tremor, vertigo and more, visible to other players.
- **Hallucinations:** players who aren't really there join, chat and stand in the distance.
- **Events, game modes, a 3D intro cutscene with your own skin, custom sounds.**
- **Configurable** in `config/bonebroke.json`.

## Install

Needs **Fabric 1.21.1** and **Fabric API**. **Simple Voice Chat** is optional. Install on the server **and** every player.

- **Dawn / Modrinth App / Prism:** import `Bonebroke.mrpack` from the release.
- **Any other launcher:** make a Fabric 1.21.1 profile, then put `bonebroke-0.1.0.jar` plus [Fabric API](https://modrinth.com/mod/fabric-api) in its `mods` folder.

Full steps for every launcher are in `README.txt` in the release.

## Commands

- `/bb start debt|championship|race` (op): start a round
- `/bb afflict <player> [condition]` (op): give a condition
- `/bbintro`: replay the intro

No real money is involved. All gambling uses in-game cash only.
